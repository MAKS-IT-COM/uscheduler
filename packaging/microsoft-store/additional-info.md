# Microsoft Store additional info

Paste into Partner Center → Store listings. Field limits are from [Add additional information](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msix/add-additional-information).

## Copyright and trademark info

200 characters.

```text
© Maksym Sadovnychyy (MAKS-IT). Apache License 2.0.
```

## Additional license terms

Leave this blank only when customers should be licensed solely under the Standard Application License Terms. This product is Apache 2.0 ([LICENSE.md](../../LICENSE.md)), so paste the license URL. A single URL is shown to customers as a link. Plain text is limited to 10,000 characters.

```text
http://www.apache.org/licenses/LICENSE-2.0
```

## Developed by

255 characters. This is separate from **Published by**, which stays the publisher display name on the account.

```text
Maksym Sadovnychyy (MAKS-IT)
```

The listing description is in [description.md](description.md). Product features are in [product-features.md](product-features.md). Keywords are in [keywords.md](keywords.md).
