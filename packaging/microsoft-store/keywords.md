# Microsoft Store keywords

Paste into Partner Center → Store listings → **Keywords**. One keyword per line. Hidden from customers.

Up to 7 keywords. 40 character limit for each keyword. No more than 21 separate words across all keywords.

```text
PowerShell scheduler
Windows service
script schedule
task scheduler
Hyper-V backup
file sync
Windows Update
```

The listing description is in [description.md](description.md). Product features are in [product-features.md](product-features.md).
