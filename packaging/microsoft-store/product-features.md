# Microsoft Store product features

Paste into Partner Center → Store listings → **Product features**.

Short summaries of the product's key features. The Store shows them as a bulleted list. Up to 20 app features. Each feature is at most 200 characters. Paste the sentence only; Partner Center adds the bullet.

- The window and the Windows service are the same program. Register, start, stop, and unregister ask for approval in place. The window stays unelevated.
- Edit when a script runs, then Launch to start it now. That run ignores the schedule and the minimum interval.
- Keep a console program running under the service. It starts and stops with the service, and restarts when it exits.
- Scripts show a description and platform. A script for the other operating system stays in the list, grayed out, and does not run.
- Example scripts ship disabled: Hyper-V backup, Windows Update, file sync, and a pure PowerShell folder sync. Enable the ones you want.
- Read service logs and script logs in the window. An unhandled error opens a window you can copy.
- After an upgrade, What's New lists additions since the version you last opened.

The listing description and the other Store text fields are in [description.md](description.md).
